# Collaboration Demo Project

This project is used to practice Git and GitHub collaboration workflows.

## How to contribute
- Open an issue
- Create a branch
- Submit a pull request

## Main Feature

This project demonstrates a simple GitHub collaboration workflow.
Contributors can use Issues, branches, Pull Requests, code review, and CI
to safely collaborate on the project.
